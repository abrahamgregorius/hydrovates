Create an astonishing, award-winning landing page for an AI-powered flood early warning platform called “Early Risk”.

The product is a low-cost, lightweight, accessible AI assistant designed to help ordinary people and communities understand flood risk before it becomes dangerous. It predicts flood risk using weather, rainfall, geographic, and historical flood data, then communicates the risk in a simple, actionable way.

The landing page should feel like a combination of:

- Apple-level visual polish
- Linear-style product design
- Google DeepMind-level AI credibility
- Modern climate-tech / civic-tech aesthetics
- A premium startup that could realistically win a global innovation competition

## CORE DESIGN DIRECTION

Do NOT create a generic SaaS landing page.

The website should immediately communicate:

“Know the risk. Act before the water rises.”

The emotional journey should be:

Awareness → Understanding → Trust → Urgency → Action.

Use a sophisticated visual language combining:

- Deep navy / near-black backgrounds
- Electric cyan / aqua accents
- Subtle blue gradients
- Soft white typography
- Glassmorphism used sparingly
- Atmospheric water/rain textures
- Animated topographic / geographic patterns
- Subtle radar and weather visualization
- Beautiful data visualization
- Generous whitespace
- Large editorial typography

Avoid excessive rounded cards, excessive gradients, stock illustrations, cartoon graphics, and generic AI imagery.

- A highlighted location

## INTERACTIONS & ANIMATIONS

Make the landing page feel alive.

Use:

- Smooth scroll
- Scroll-triggered animations
- Subtle parallax
- Animated radar sweeps
- Animated rainfall particles
- Number counters
- Map transitions
- Gradient movement
- Data flowing through the AI pipeline
- Hover states
- Micro-interactions
- Soft page transitions

Animations must feel intentional and premium.

Avoid excessive animation that hurts readability or performance.

## TYPOGRAPHY

Use a modern premium sans-serif font such as:
Inter, Geist, Satoshi, or Manrope.

Use:

- Huge hero typography
- Tight letter spacing
- Strong visual hierarchy
- Short paragraphs
- Editorial-style section headings

Typography should carry much of the visual identity.

## RESPONSIVE DESIGN

Design mobile-first.

On mobile:

- Hero becomes vertically stacked
- Map visualization remains prominent
- Dashboard transforms into a swipeable/card-like experience
- Navigation becomes minimal
- Typography scales beautifully
- Animations remain performant
- CTAs remain easy to reach

Do not simply shrink the desktop design.

## PERFORMANCE

Despite the visual richness, the landing page must remain lightweight.

Avoid:

- Huge video backgrounds
- Heavy 3D libraries
- Excessive image assets
- Unnecessary dependencies

Prefer:

- CSS animations
- SVG
- lightweight canvas where appropriate
- optimized assets

The visual design should communicate the philosophy of the product itself:

“Powerful intelligence without unnecessary infrastructure.”

## TECHNICAL IMPLEMENTATION

Build it as a production-quality modern web application.

Preferred stack:

React
Vite
Tailwind CSS
TypeScript
Framer Motion

Use reusable components and clean architecture.

Create:

- responsive navigation
- Hero
- Trust section
- Problem section
- Product preview
- AI pipeline
- Accessibility section
- Community section
- Live risk map
- Final CTA
- Footer

Make the entire experience cohesive.

## IMPORTANT DESIGN RULE

The final result should NOT look like:

“another AI SaaS landing page.”

It should feel like a serious climate-tech product with a strong social mission.

The first 5 seconds should make the visitor understand:

1. This helps predict floods.
2. It uses AI.
3. It is designed for ordinary people.
4. It can help people act earlier.
5. The product feels trustworthy and technically sophisticated.

Aim for the visual quality of a product featured on Awwwards, Framer, Linear, or a top-tier startup launch.

Make it beautiful enough that a competition judge would immediately want to explore the product.
